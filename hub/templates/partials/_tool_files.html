{# The remote file explorer. One card, because it is one thing: a folder, and what you can do to what is in it. Splitting the toolbar and the list into separate folds would put a scroll between the Delete button and the row it is about. Every action button is DISABLED in the markup and enabled by files.js against the current selection. Rendering them enabled and refusing on click would teach an operator that the toolbar lies; rendering them absent would make the toolbar jump as rows are selected. Note there is no capability gate anywhere in here. Unlike the Firmware and Network panels -- whose read halves are inventory and whose write halves need `issue_commands` -- every route behind this panel needs `issue_commands`, browsing included. tools.html does not render the tab at all without it, so a gate here would be a second, quieter copy of a decision already made. See hub/files_web.py for why browsing is on that side of the line. #}

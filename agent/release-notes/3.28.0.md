The machine page updates every second while you have it open.

**A minute-wide chart drawn from a dozen points is a chart you cannot use.** Machines report
every five seconds, and only every second report carried the sensor block the CPU Load,
Memory, GPU, fan and power panels are drawn from — so those panels moved about six times a
minute. "Open that program and let's watch what it does" did not work: a spike lasting three
seconds was one dot, or none at all.

Now, while somebody has a machine's page open and in front, that machine reports **every
second**, with a full sensor block every time. Every panel moves at the same rate, and a
short spike is a shape rather than a dot. Nothing to turn on and nothing to configure.

**Only the machine you are looking at, and only while you are looking.** The page tells the
hub it is being watched; the machine asks the hub about that every couple of seconds and
speeds up when the answer is yes. Close the tab, switch to another tab, pick a past day, or
let the laptop sleep, and the machine is back to its ordinary five-second cadence within
about twenty seconds — including when the browser is killed outright, because the watch
expires on its own rather than waiting for a goodbye message that would never arrive.

A fleet nobody has open costs exactly what it cost before. This is the same bargain the
Processes card already strikes, and the two now share one request rather than making one
each.

**What it costs while you are watching.** That one machine sends roughly twelve times the
telemetry it usually does — a few tens of KB per second — and the hub stores a reading per
second for it. That is per open page, not per machine in the fleet, and it stops when you
stop looking. Charts of that period keep the extra detail; older data is unaffected.

**This needs hub 1.77.0 or newer.** Against an older hub the agent asks, is answered the way
it always was, and reports on the old cadence — nothing breaks and nothing needs
configuring, you simply don't get the faster page until the hub is updated. An agent still on
3.27.0 works fine against the new hub too, so the two halves can land days apart, in either
order.

**If it misbehaves.** A machine that stays fast after you close the page is a watch that has
not lapsed yet — give it twenty seconds. A page that never speeds up is either an agent
below 3.28.0 (check the version on the machine page) or a hub below 1.77.0. Either way the
page keeps working exactly as it did before, at the old rate; there is no state to clear and
nothing to restart.
